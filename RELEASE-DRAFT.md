# Mini Kota Göstergesi 1.0.2.0 — imzasız deneysel ön sürüm

Windows x64 · TR/EN · MIT · Copyright (c) 2026 arcah

Codex kotasını gösteren bağımsız taşınabilir Windows uygulaması. Kurulu Codex
ve mevcut oturum gerekir. ChatGPT masaüstü işlemi açıkken görünür.
OpenAI tarafından geliştirilmemiştir veya onaylanmamıştır.

**İkili dosya imzasızdır. SignPath başvurusu henüz gönderilmedi; kabul veya imza
yoktur. Windows tarafından engellenebilir. Güvenlik ayarlarını değiştirmeyin.**

Derleme ve ürün/sürüm bilgileri kontrol edildi. EXE çalıştırılmadı. Canlı kota,
kapanış/uzun çalışma, DPI ve çoklu monitör testleri tamamlanmamıştır. Önceki
AppHangB1 kaydı çözülmüş sayılmaz. Bu sürüm kararlı olarak sunulmaz.

yayıncı imzası veya Windows çalıştırma izni sağlamaz.
